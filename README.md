# 🎓 FSLMS — Family School Learning Management System

> 🚀 A modern school management system built as an **INSA Summer Camp 5th Batch graduation project**.

## 📚 About

**FSLMS (Family School Learning Management System)** is a school management platform designed to connect students, parents, teachers, and school administrators in one system.

The goal is to make learning management, communication, academic tracking, and school administration easier and more organized. 💻📖

## ✨ Features

* 🔐 Student, Parent, Teacher & Director authentication
* 👨‍🎓 Student dashboard
* 👨‍👩‍👧 Parent communication
* 👨‍🏫 Teacher management
* 🏫 School administration
* 📊 Academic results and grades
* 📅 Study planner
* 🔔 Notifications
* 💬 Communication system
* ⚙️ Settings
* 🌙 Light & Dark mode
* 📱 Responsive interface

## 🛠️ Technologies

* 🎯 Flutter
* 💙 Dart
* 🗄️ Supabase
* 🔐 Supabase Authentication
* 🗃️ PostgreSQL
* 🌐 REST APIs
* 📱 Responsive UI

## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/FSLMS.git
```

### 2️⃣ Enter the project

```bash
cd FSLMS
```

### 3️⃣ Install dependencies

```bash
flutter pub get
```

### 4️⃣ Run the application

```bash
flutter run
```

## 🔐 Backend

FSLMS uses **Supabase** for backend services, authentication, and database management.

The application communicates with the backend to manage:

* 👤 Users
* 🎓 Students
* 👨‍👩‍👧 Parents
* 👨‍🏫 Teachers
* 🏫 School data
* 📊 Academic results
* 💬 Communication
* 📅 Study planning
